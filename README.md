# PuzzlePath

Can the position alone tell us how difficult a chess puzzle will feel?

PuzzlePath tests that question with public Lichess puzzles, interpretable board
features, simple baselines, and gradient boosting. It also creates printable
practice sets with a separate answer key. It runs on a laptop without a chess
engine, API key, or GPU.

The benchmark, commands, and model limitations are documented here as the
implementation is evaluated.
